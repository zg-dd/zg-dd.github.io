llama_factory 使用介绍

Apr 11, 2026
阅读时长: 6 分钟

前置安装

说明： 工具 说明 官方下载/安装地址 NVIDIA 驱动 显卡硬件驱动，是一切的基础 NVIDIA 驱动官方下载 ：https://www.nvidia.com/Download/index.aspx CUDA Toolkit GPU 编程的开发工具包 CUDA官方下载(建议12.4) ：https://developer.nvidia.com/cuda-toolkit-archive cuDNN GPU加速库 cuDNN官方下载：https://developer.nvidia.com/cudnn Conda 包管理和环境管理工具 推荐使用miniforge：https://conda-forge.org/miniforge/

首先必须是NVIDIA显卡，显卡硬件驱动，是一切的基础 NVIDIA 驱动官方下载 ：https://www.nvidia.com/Download/index.aspx， 检查显卡是否安装成功：nvidia-smi后会显示显卡信息

安装好显卡之后，打开NVIDIA控制面板查询支持的CUDA版本

去官网下载对应版本的CUDA，CUDA官方下载：https://developer.nvidia.com/cuda-toolkit-archive，只要是支持的显卡版本以下都可以，尽量选择可支持的最新版本（我这里支持的是13.2.0）。 以上全部选择精简安装即可。检查CUDA是否安装成功：nvcc -V

然后安装cuDNN：cuDNN官方下载：https://developer.nvidia.com/cudnn . 安装最新版本即可。

然后安装Conda：推荐使用miniforge：https://conda-forge.org/miniforge/, 如果本地有安装Python环境，也没有关系，可以安装。为的是方便创建虚拟环境，使用。

创建虚拟环境

我这里是用的是mamba ，使用canda也可以，但是mamba速度更快，我当前情况是，安装canda之后mamba已经存在，如果不存在可以使用以下命令安装（都是在终端命令执行）：

conda install -c conda-forge mamba

创建虚拟环境llama_factory：

# 这里需要注意， -n是虚拟环境名称，-p是虚拟环境路径+名称，-n和-p只能使用一个参数，这里我使用的是-p；注意python=3.12版本号。有时候可能应为版本过低会导致拉取操作失败。一般建议在在3.10以上尝试。-y是自动安装依赖包
mamba create -p "F:\llama_factory\env" python=3.12 -y

激活环境： 创建虚拟环境成功之后，进入虚拟环境：

mamba activate "F:\llama_factory\env"

接下来就可以尽情使用python以及环境安装了。

安装PyTorch

确保安装的PyTorch与CUDA版本环境兼容（我这里是13.2.0）。直接从PyTorch官方使用pip安装，这通常能获得更好的CUDA支持。PyTorch与CUDA对照命令查看 。 复制命令在虚拟环境安装执行：

#这里是参考，具体到官网查询指定命令
pip install torch==2.10.0 torchvision==0.25.0 torchaudio==2.10.0 --index-url https://download.pytorch.org/whl/cu130

安装完成后，检验，pytorch是否能正常识别CUDA：

python -c "import torch; print(f'PyTorch版本: {torch.__version__}'); print(f'PyTorch使用的CUDA版本: {torch.version.cuda}'); print(f'CUDA是否可用: {torch.cuda.is_available()}'); print(f'当前GPU设备: {torch.cuda.get_device_name(0)}')"

我本机运行结果

PyTorch版本: 2.10.0+cu130
PyTorch使用的CUDA版本: 13.0
CUDA是否可用: True
当前GPU设备: NVIDIA GeForce RTX 3060 Laptop GPU

安装LLaMa-factory：

  1. 克隆LLaMA-Factory仓库，或者去官网下载：https://github.com/haotian-liu/LLaMA-Factory
git clone --depth 1 https://github.com/hiyouga/LLaMA-Factory.git
# 进入项目目录
cd LLaMA-Factory
  1. 安装LLaMA-Factory及其依赖，指定使用清华镜像源以加速下载(这里我当初执行失败了，查看是python版本安装了3.10，之后我就更换为3.12，成功安装)
pip install -e ".[torch,metrics]" -i https://pypi.tuna.tsinghua.edu.cn/simple
  1. 验证安装 安装完成后，通过以下命令验证LLaMA-Factory是否安装成功：
llamafactory-cli version

如果该命令能正确输出LLaMA-Factory的版本号，说明安装成功。

  1. 启动与使用 安装成功后，你可以在安装目录下，使用Dos命令启动LLaMA-Factory的Web界面进行可视化操作：
llamafactory-cli webui

启动成功后，访问http://localhost:7860/，即可进入LLaMA-Factory的Web界面。

训练模型

这里使用一个简单模型训练：Qwen2.5-0.5B-Instruct 模型

{
  "train-fc-1000": {
    "file_name": "train-fc-1000.json"
  },
  ...
  1. 配置训练参数：

注意：：我的笔记本是16G，模型训练默认启用16个进程并发进行。这里启动时出现了内存溢出。

这里需要额外配置了其他参数以此解决这个问题，preprocessing_num_workers参数含义是预处理数据时使用的进程数：

{"optim": "adamw_torch","preprocessing_num_workers": 8}
  1. 加载模型，测试效果：

  1. 导出模型，在Chat同级菜单路径有Export按钮，调整必要参数，我这里只调整了导出目录，点击导出，保存模型。

  2. 模型加载：

模型下载导出完成之后, 在导出目录下，存在Modelfile文件，可以通过ollama加载自己训练好的模型：

# mymodel 可自定义，为模型名称，./Modelfile为模型文件路径，可使用绝对路径，也可使用相对路径（前提在当前目录下）
ollama create mymodel -f ./Modelfile

注：我这里可能因为下载LLaMA-Factory版本问题，加载模型可以成功，启动模型时聊天会报错500，但是跑官方qwen2.5-0.5B-Instruct模型没有问题。了解后，发现可能LLaMA-Factory内置的llama.cpp 版本太低导致的。这里采用单独的llama.cpp 模型转换： 第一步：克隆 llama.cpp

git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
pip install -r requirements/requirements-convert_hf_to_gguf.txt

第二步: 转换模型

# I:\ai-model\train_2026-04-11-12-40-19 是训练的模型路径，I:\ai-model\qwen-finetuned.gguf 是转换后的模型路径
python convert_hf_to_gguf.py "I:\ai-model\train_2026-04-11-12-40-19" --outtype f16 --outfile "I:\ai-model\my-qwen\qwen-finetuned.gguf"

第三步：在I:\ai-model\my-qwen目录下创建Modelfile文件，内容是：

FROM I:\ai-model\my-qwen\qwen-finetuned.gguf

TEMPLATE """{{ if .System }}<|im_start|>system
{{ .System }}<|im_end|>
{{ end }}{{ range .Messages }}{{ if eq .Role "user" }}<|im_start|>user
{{ .Content }}<|im_end|>
<|im_start|>assistant
{{ else if eq .Role "assistant" }}{{ .Content }}<|im_end|>
{{ end }}{{ end }}"""

SYSTEM """You are Qwen, created by Alibaba Cloud. You are a helpful assistant."""

PARAMETER stop "<|im_end|>"
PARAMETER num_ctx 4096

Modelfile文件主体内容和源导出文件一致，只是在开头添加了FROM参数，指定模型文件路径。FROM I:\ai-model\my-qwen\qwen-finetuned.gguf

然后通过如下命令重新安装模型：

# 移除旧模型
ollama rm mymodel-Qwen2.5-0.5B-Instruct
# 安装新模型
ollama create mymodel-Qwen2.5-0.5B-Instruct -f I:\ai-model\my-qwen\Modelfile
# 测试运行模型
ollama run mymodel-Qwen2.5-0.5B-Instruct "hello"
