💭 今日想法

每个人生来孤独，即使有亲朋好友，甚至恋人。都有难以言表的情绪。难以言表也许是自己太过实诚，知道自己的低能量状态，不想传染给别人吧，并且即使低头了，那又能怎么样，谁又能帮我呢？

如今的处境是我自作自受，是我自己没有珍惜机会，能怪谁呢？ 但是话又说回来，当前离职是因为以前的太过自负，觉得自己可以拥有更好的，盲目的自负迷失了自我，却不知道我想要的已经得到了。

挫败后，我已经失去了曾经的信仰-真理、真相、实力，那我 还能相信什么呢？什么是真的，什么才是坚持活下去的理由呢？

面试连连失败，我好像会的很多，又好像什么也不会，今天面试问了一个问题：一张user表，username有重复，请问查询username重复数量最多的前三个的SQL语句怎么写？曾经那么简单的语句，不就是slect count() from user group by username order by count() desc limit 3么，我竟然支支吾吾想了半天，又是考虑子查询，又是考虑count(1)和count(*)的性能等等，却想不出来这么简单的语句。

突然一下就想到悟空被通背猿猴要挟打到武功尽失，能力全废的感觉。可我不是孙悟空，不知道能否再次翻身。

任何的事情的发生是必然的，好事发生是因为你值得拥有此刻，坏事发生事是要你反思自己的过错，重新踏上新的历程。我只不过是把中年焦虑提前到了29岁而已，那又怎么样？又不是没有翻身机会，任何时候都不晚。即使我重新入职场，挣钱，我已经看明白了，一定要搞副业，不能在一棵树上挂死。我起码比很多人提前明白这个道理。

📝 想对自己说的话

你不能颓废，即使问1+1=几，你回答3，也要坚强，你必须始终相信自己，毕竟曾经的自己也为理想目标奋斗，也是人群中的佼佼者。即使跌倒无数次，失败千万次，也要继续坚持，不能暗示自己已经失败了，你才29，还拥有大好未来，你必须得暗示自己，你很好，相信自己会交好运，只有相信自己才能找到工作，重启人生，相信自己，相信自己，相信自己。如果你自己都放弃了，那谁也扶不起来，这样的你才是真正的失败者。
